# Customer Retention & Churn Analysis

## Project Overview
This project analyzes customer retention and churn using the Telco Customer Churn dataset. It explores customer behavior, identifies churn patterns, and presents business insights through an interactive Power BI dashboard.

## Objectives
- Analyze customer churn and retention.
- Understand churn patterns across contract types.
- Compare churn across payment methods and internet services.
- Explore the relationship between customer tenure and churn.
- Analyze monthly and total customer charges.
- Present findings through interactive visualizations.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Power BI
- DAX

## Project Workflow
1. Import the original customer dataset.
2. Clean and prepare the data using Python in Jupyter Notebook.
3. Export the cleaned dataset to CSV.
4. Import the cleaned data into Power BI.
5. Create DAX measures and KPI cards.
6. Develop interactive charts and filters.
7. Analyze customer churn and retention patterns.

## Dashboard Analysis
- Customer Churn Distribution
- Churn by Contract Type
- Churn by Payment Method
- Churn by Tenure
- Churn by Internet Service
- Average Monthly Charges by Churn
- Average Total Charges by Customer Status

## Key Findings
The dashboard examines customer churn patterns across contract types, payment methods, internet services, tenure, and charges. Specific findings should be confirmed from the completed analysis.
